# 🎵 SoundWave — Music Player

A modern and responsive music player built using HTML, CSS, and JavaScript as part of the Horizon TechX Frontend Development Internship.

## 🚀 Live Demo

https://sajjadursohag.github.io/Music_Player/

## 📸 Screenshot

![SoundWave Music Player](screenshots/music_player.png)

## ✨ Features

- Play and pause music
- Next and previous track controls
- Display song title and artist name
- Show current playback time and total duration
- Interactive progress bar for seeking
- Volume control
- Automatically play the next song
- Responsive dark-themed interface
- Custom playlist using local audio files

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- HTML Audio API

## 📂 Project Structure

- `index.html` — Music player structure
- `style.css` — Styling and responsive layout
- `script.js` — Audio controls and playlist logic
- `songs/` — Audio files
- `screenshots/` — Project screenshot

## 💻 Run Locally

1. Clone the repository:

   git clone https://github.com/sajjadursohag/HorizonTechX_Music_Player.git

2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
4. Add your own MP3 files to the `songs/` folder.
